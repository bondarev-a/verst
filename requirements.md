# text_workspace — требования

Статус: версия 0.4.2. Окно на GTK собрано, пакет для Ubuntu называется `verst`. Готовый `.deb` выкладывается в релизы репозитория.
Источник: постановка от 2026-10-06 и интервью.
Имя каталога рабочее, его можно сменить.

## 1. Проблема

Нужен локальный инструмент для чтения и правки текстовых файлов с навигацией уровня IDE. Основной тип файлов — Markdown. Окно не привязано к одному проекту: обход доступен по всему диску, а каталог (обычно отдельный репозиторий) можно запинить как рабочее пространство.

## 2. Цель

Десктопное приложение на Rust и GTK 4 для Linux, в котором можно:

- открыть любой текстовый файл на диске и править его в GtkSourceView;
- держать несколько запиненных каталогов и переключаться между ними;
- видеть исходник Markdown и живой предпросмотр рядом;
- искать по содержимому и ходить по связям заметок внутри активного пина;
- наращивать ядро через швы команд, панелей, языков и тем;
- менять масштаб всего окна клавишами `Ctrl++` и `Ctrl+-`.

## 3. Зафиксировано

| ID | Решение |
|----|---------|
| D-1 | Предмет — текстовые файлы. Главный сценарий — Markdown. Прочие текстовые форматы тоже открываются и редактируются. |
| D-2 | Навигация по файлам и по содержимому открытого файла — как в IDE, а не как в простом просмотрщике. |
| D-3 | Приложение сразу работает по всему диску. Запиненное рабочее пространство не является обязательным режимом запуска. |
| D-4 | Каталог можно запинить вкладкой «рабочее пространство». Типичный объект — корень отдельного репозитория. Наличие git для пина не требуется. |
| D-5 | Целевая архитектура — плагины по образцу VS Code. Первая версия не грузит чужой код. Обязательные швы: команды, панели, языки, темы. Встроенные поиск, оглавление, предпросмотр и связи ходят через эти швы. |
| D-6 | Форма — отдельное десктопное окно. Файлы читаются и пишутся напрямую с локального диска. Содержимое файлов не покидает машину. |
| D-7 | У открытого файла один режим: редактирование или предпросмотр. Предпросмотр строится из текущего буфера. Быстрая заметка каждый раз открывается в редактировании. |
| D-8 | Вкладка пространства — закладка на каталог. Набор открытых файлов общий на окно. |
| D-9 | Навигация первой версии: ленивое дерево всего диска, дерево запиненного каталога, список открытых файлов в боковой панели, поиск по содержимому, оглавление Markdown, несколько панелей редактора. |
| D-10 | Продукт совмещает редактор файлов и связи между Markdown внутри активного пина: относительные ссылки, вики-ссылки `[[имя]]`, панель входящих ссылок, граф. |
| D-11 | Стек первой версии: Rust, Cargo, GTK 4, GtkSourceView, предпросмотр Markdown через WebKit. Платформа — Linux. Свой текстовый редактор не пишется. |
| D-12 | Клик по файлу в списке открытых подставляет его в фокусную панель. Полоски вкладок файлов нет. |
| D-13 | Поиск по содержимому, входящие ссылки и граф работают только внутри активного пина. Исходящие ссылки открытого файла берутся из его текста: цели внутри активного пина, а если сам файл лежит в другом запиненном каталоге — внутри того каталога. Без пина эти функции недоступны. Файл вне корня пина открыть можно, пин при этом остаётся. |
| D-14 | Файл пишется и явно, и автоматически. Несохранённое отличие буфера от диска видно. Внешняя правка открытого файла показывается как конфликт с вопросом пользователю. |
| D-15 | Перезапуск восстанавливает запиненные каталоги, список открытых файлов и масштаб окна. |
| D-16 | Подсветка синтаксиса зависит от типа файла, для Markdown и для остальных текстовых типов. |
| D-17 | Дочерние элементы каталога в дереве читаются при раскрытии узла. |
| D-18 | Масштаб всего окна меняется как в IDE: `Ctrl++` увеличивает, `Ctrl+-` уменьшает. Масштаб общий для дерева, списка файлов, редактора и предпросмотра. Сочетания встроены в ядро. |

| MD-2 | Предпросмотр строится из текущего буфера, до записи на диск. | принято |
| MD-3 | Клик по относительной ссылке Markdown открывает целевой файл. | принято |
| MD-4 | Вики-ссылка `[[имя]]` разрешается в файл внутри активного пина и открывает его. | принято |
| MD-5 | У текущего файла есть панель входящих ссылок. | принято |

## 7. Вне первой версии

- Полоска вкладок файлов.
- Шов привязок клавиш, загрузчик плагинов, маркетплейс, extension host.
- Встроенный git-клиент.
- Публикация заметок и отдельная база знаний.
- Windows и macOS.
- Совместное редактирование, сетевые диски как режим, доступ к чужой машине.

## 8. Открытые вопросы

Продуктовых вопросов нет. При реализации зафиксированы такие умолчания: в дереве проводника и пространства двойной щелчок и Enter раскрывают каталог, файл открывается двойным щелчком; содержимое каталога в центральной колонке берётся из меню строки; слева разделы стоят вертикальной панелью в порядке Проводник, Пространства, Заметки, Открытые, История; быстрая заметка лежит вне пина, открывается в редакторе и удаляется после подтверждения; предпросмотр заполняется только для Markdown; вики-ссылка с несколькими совпадениями показывает список; клик по узлу графа открывает файл; автосохранение срабатывает через 800 мс после правки.
