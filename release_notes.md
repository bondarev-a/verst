# Заметки к версиям

Текст раздела текущей версии попадает в описание релиза на GitHub. Заголовок раздела — ровно `## X.Y.Z`, без лишних слов. Новый раздел пишется сверху, над предыдущими.

## 0.7.0

- Переключение файлов не зависает: Markdown раскрашивается за линейное время, таблицы строятся только для видимой панели и не тормозят при уходе с файла.
- Переход с файла с таблицами на другой файл больше не закрывает программу.
- Набор текста в больших файлах не тормозит: ссылки и теги пересчитываются только для изменённых файлов и после паузы.
- Заголовок окна в одну строку: меню, назад и вперёд, имя файла, вид (`Ctrl+E`), булавка, каталог и масштаб «Aa». Открытые файлы — первый раздел левой панели, переход по ним — `Ctrl+PgDn` и `Ctrl+PgUp`.
- Знаки разметки скрыты и видны на строке с курсором. Вики-ссылки показаны как ссылки.
- Длинный текст в ячейке таблицы переносится по ширине колонки, таблица помещается в редактор. Перенос строк включён по умолчанию.
- Уход с ячейки таблицы сохраняет её текст и не блокирует ввод в другом файле.
- Без аппаратного 3D окно рисуется через cairo: запуск почти вдвое быстрее.

## 0.6.1

- У файла два вида: редактирование и просмотр. В Markdown редактирование сразу показывает собранный текст и таблицы сеткой. Отдельного режима рендеринга больше нет.
- Ошибка чтения метаданных не стирает открытые файлы и не закрывает программу. Окно появляется до обхода всего пространства.
- Код под GNU GPL версии 3 или новее: программу можно копировать и развивать своей версией.

## 0.6.0

- Выделенный фрагмент можно отправить в AI чипом «Отправить в AI». В запрос уходит только этот фрагмент и вопрос. Ответ заменяет выделение или вставляется ниже.
- Доступ к модели задаётся в настройках: адрес, модель, ключ или имя переменной окружения. Ключ хранится отдельно от сессии.
- Что было отправлено и что пришло, видно в разделе «История», под недавно открытыми файлами.
- В режиме рендеринга строка под курсором сохраняет тот же шрифт. Моноширинным остаётся код.

## 0.5.1

- В ячейке таблицы виден курсор. Стрелки двигают его по тексту, Shift выделяет фрагмент, набор вставляет символ на месте курсора и не стирает остальной текст.
- Ctrl+Z и Ctrl+Y в ячейке отменяют набранное и не закрывают окно.
- Масштаб окна (`Ctrl++` / `Ctrl+-`) отделён от масштаба текста (`Ctrl+Shift++` / `Ctrl+Shift+-`).

## 0.5.0

- Прокрутка после переключения открытого файла не роняет окно. Последняя строка больше не прилипает к верху редактора.
- В режиме рендеринга работают стандартные отмена и повтор, в том числе из ячейки таблицы. Курсор в таблице отличается от фона.
- Путь над проводником, пространством и заметками можно набрать вручную.
- Предпросмотр HTML и граф не пересчитываются на каждое нажатие клавиши, если файл не в режиме просмотра.

## 0.4.7

- Переключение открытых файлов оставляет их на местах в полосе и открывает файл там, где курсор был в прошлый раз.
- Вид текущего файла переключается одним списком «Вид» над текстом. В настройках «Открывать» остаётся значением по умолчанию для файла без своего вида.
- Режим рендеринга больше не разбирает весь файл на каждое движение курсора. Таблицы остаются сеткой, а не уменьшенной копией. Прокрутка длинного файла не роняет окно.

## 0.4.6

- Под меню «Файл» полоса «Открытые файлы»: щелчок открывает файл, крестик закрывает, текущий файл подсвечен.
- Раздел «Пространства» открывается списком. Выбор пространства показывает его дерево, повторный вход — снова список.
- У Markdown три вида: редактирование, рендеринг и просмотр. Рендеринг правит тот же текст: заголовки и выделение собраны, таблица — сетка. Страница просмотра остаётся чтением и источником PDF.
- Файл в каталоге и в дереве пространства открывается одним щелчком. Свёрнутая левая панель разворачивается той же кнопкой.

## 0.4.5

- README описывает программу по разделам: файлы, заметки, навигация, клавиши.
- Заметки к версии лежат в этом файле. Сборка подставляет раздел текущей версии в текст релиза.

## 0.4.4

- «Сохранить как» (`Ctrl+Shift+S`) записывает текущий текст в выбранный файл и переводит открытый документ на него. Прежний файл на диске остаётся в последнем сохранённом виде.
- «Сохранить PDF» записывает страницу предпросмотра Markdown: лист A4, фон блоков кода, картинки из каталога файла.

## 0.4.3

- Пуш в `main` собирает пакет Ubuntu и выкладывает `verst_<версия>_amd64.deb` в релизы репозитория.

## 0.4.2

- В релизах появился готовый пакет Ubuntu: ставить программу можно без сборки из исходников.
- Файл из проводника или пространства можно перетащить в другое приложение. Файл, брошенный на окно извне, открывается.

## 0.4.1

- Над текстом показан полный путь к открытому файлу.
- Над левой панелью показан каталог, который сейчас активен в проводнике, пространстве или заметках.

## 0.4.0

- Первая опубликованная сборка окна Verst: проводник по диску, запиненные пространства, быстрые заметки, предпросмотр Markdown, поиск и связи внутри пина.
- Локальная копия в `~/.local/bin` запускается, когда песочница WebKit не может вызвать bubblewrap.
