# Заметки к версиям

Текст раздела текущей версии попадает в описание релиза на GitHub. Заголовок раздела — ровно `## X.Y.Z`, без лишних слов. Новый раздел пишется сверху, над предыдущими.

## 0.4.6

- Под меню «Файл» полоса «Открытые файлы»: щелчок открывает файл, крестик закрывает, текущий файл подсвечен.
- Раздел «Пространства» открывается списком. Выбор пространства показывает его дерево, повторный вход — снова список.
- У Markdown три вида: редактирование, рендеринг и просмотр. Рендеринг правит тот же текст: заголовки и выделение собраны, таблица — сетка. Страница просмотра остаётся чтением и источником PDF.
- Файл в каталоге и в дереве пространства открывается одним щелчком. Свёрнутая левая панель разворачивается той же кнопкой.

## 0.4.5

- README описывает программу по разделам: файлы, заметки, навигация, клавиши.
- Заметки к версии лежат в этом файле. Сборка подставляет раздел текущей версии в текст релиза.

## 0.4.4

- «Сохранить как» (`Ctrl+Shift+S`) записывает текущий текст в выбранный файл и переводит открытый документ на него. Прежний файл на диске остаётся в последнем сохранённом виде.
- «Сохранить PDF» записывает страницу предпросмотра Markdown: лист A4, фон блоков кода, картинки из каталога файла.

## 0.4.3

- Пуш в `main` собирает пакет Ubuntu и выкладывает `verst_<версия>_amd64.deb` в релизы репозитория.

## 0.4.2

- В релизах появился готовый пакет Ubuntu: ставить программу можно без сборки из исходников.
- Файл из проводника или пространства можно перетащить в другое приложение. Файл, брошенный на окно извне, открывается.

## 0.4.1

- Над текстом показан полный путь к открытому файлу.
- Над левой панелью показан каталог, который сейчас активен в проводнике, пространстве или заметках.

## 0.4.0

- Первая опубликованная сборка окна Verst: проводник по диску, запиненные пространства, быстрые заметки, предпросмотр Markdown, поиск и связи внутри пина.
- Локальная копия в `~/.local/bin` запускается, когда песочница WebKit не может вызвать bubblewrap.
