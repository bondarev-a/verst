# Verst

Версия 0.4.2.

Локальный редактор текстовых файлов с навигацией уровня IDE. В меню и на ярлыке программа называется Verst: слева исходник, справа уже собранная страница. Иконка лежит в `packaging/verst.png`. Основной формат — Markdown, остальные текстовые файлы тоже открываются. Обход сразу по всему диску; каталог можно запинить как пространство. Поиск, входящие ссылки и граф считаются внутри активного пина. Исходящие ссылки открытого файла берутся из его текста и ведут в тот запиненный каталог, где лежит файл.

Границы продукта — в [requirements.md](./requirements.md).

## Назначение

Чтение и правка текстовых файлов на локальном диске. Запиненный каталог, обычно корень репозитория, задаёт область поиска и связей между Markdown-файлами.

Быстрая заметка (`Ctrl+N` или меню «Файл») создаётся в личном каталоге `~/.local/share/text_workspace/notes` и сразу открывается в режиме редактирования. Список живёт в разделе «Заметки», отдельно от пространства. Теги пишутся в тексте как `#тема`. Меню «Группировка» рядом с «Новая заметка» собирает список без групп, по дате создания, по дате изменения или по тегам. Список тегов по умолчанию свёрнут: раскрытие показывает до трёх строк, кнопка «Все теги» поднимает предел до пяти строк и включает прокрутку. Заметку можно удалить из её строки; программа сначала спрашивает подтверждение. Кнопка «В пространство» сначала спрашивает, в какое пространство перенести заметку, затем открывает диалог сохранения уже в каталоге этого пространства.

Слева разделы стоят вертикальной панелью: Проводник, Пространства, Заметки, Открытые, История. У каждой иконки есть подсказка. Внизу панели — булавка и кнопка сворачивания. Справа остаются вкладки «Оглавление», «Поиск», «Ссылки» и «Граф». Навигацию и блок «О файле» можно свернуть; булавка фиксирует их открытыми.

## Стек

- язык / runtime: Rust
- пакетный менеджер: Cargo
- основные зависимости: GTK 4, GtkSourceView 5, WebKitGTK 6
- платформа: Linux

## Установка на Ubuntu

Нужна Ubuntu 24.04 или новее, архитектура amd64. На машину, куда ставят уже собранный пакет, Rust не нужен. Пакет зависит от `libgtk-4-1`, `libgtksourceview-5-0`, `libwebkitgtk-6.0-4`, `bubblewrap`, `xdg-dbus-proxy` и AppArmor. На Ubuntu 22.04 этих библиотек нет.

Готовый пакет лежит в [релизах](https://github.com/bondarev-a/verst/releases): файл `verst_<версия>_amd64.deb`. Компилятор для установки не нужен.

```bash
wget -O verst_0.4.2_amd64.deb \
  https://github.com/bondarev-a/verst/releases/download/v0.4.2/verst_0.4.2_amd64.deb
sudo apt install ./verst_0.4.2_amd64.deb
```

После установки программа называется `verst` и появляется в меню.

## Сборка

Собрать пакет можно на Ubuntu 24.04+, где стоят Rust и заголовки библиотек.

```bash
curl --proto '=https' --tlsv1.2 -sSf https://sh.rustup.rs | sh
sudo apt install pkg-config libgtk-4-dev libgtksourceview-5-dev libwebkitgtk-6.0-dev
./packaging/install_ubuntu.sh --deb
sudo apt install ./packaging/out/verst_0.4.2_amd64.deb
```

`./packaging/install_ubuntu.sh --deb` только собирает пакет в `packaging/out/` и ничего не ставит. Без флага скрипт ещё копирует программу в `~/.local/bin` и ставит ярлык в меню текущего пользователя. `./packaging/install_ubuntu.sh --system` ставит пакет в систему через apt.

Если `pkg-config` не видит GTK, потому что заголовки лежат в локальном префиксе, перед сборкой выполните `source ./env.sh`.

## Другие платформы

Библиотека в `src/lib.rs` не зависит от GTK: разбор Markdown, индекс ссылок, поиск, граф, сессия и масштаб. Её можно собирать на другой системе как есть.

Окно собрано в `src/ui/` на GTK 4, GtkSourceView 5 и WebKitGTK 6. Эти библиотеки есть в Linux-дистрибутивах с достаточно новым GNOME. Тот же исходник переносится на другой дистрибутив пересборкой и своими именами пакетов, не файлом `.deb` от Ubuntu.

Windows и macOS этим интерфейсом не покрываются: WebKitGTK туда не ставится как обычная библиотека. Чтобы перенести продукт, библиотеку оставляют, а `src/ui/` заменяют на окно той платформы. Предпросмотр Markdown на Windows логично отдать WebView2, на macOS — WKWebView. Путь сессии сейчас считается по XDG; для других систем его задают в `config_dir()`.

## Запуск из исходников

Те же заголовки, что и для сборки пакета:

```bash
sudo apt install libgtk-4-dev libgtksourceview-5-dev libwebkitgtk-6.0-dev pkg-config
cargo run --bin text_workspace
```

Сессия пишется в `$XDG_CONFIG_HOME/text_workspace/session.json` или в `~/.config/text_workspace/session.json`.

Меню «Файл» и «Вид»: сохранить (`Ctrl+S`), быстрая заметка (`Ctrl+N`), переход к файлу (`Ctrl+P`), запинить каталог, разделить панель, поиск. Масштаб окна: `Ctrl++` и `Ctrl+-`. На клавиатуре, где плюс набирается через Shift, срабатывает и `Ctrl+=`. В дереве проводника и пространства двойной щелчок и Enter раскрывают каталог, а по файлу открывают его. Файл из этих деревьев можно перетащить в другое приложение. Файл, брошенный на окно извне, открывается. Содержимое каталога в центральной колонке открывается из меню строки, пункт «Показать содержимое». Стрелка у строки тоже разворачивает ветку. Пространства переключаются `Ctrl+1`…`Ctrl+9`, а также `Ctrl+Tab` и `Ctrl+Shift+Tab`. У открытого файла один режим: редактирование или предпросмотр.

Если процесс сразу завершается с `Failed to fully launch dbus-proxy`, песочница WebKit не смогла вызвать bubblewrap. Для запуска в таком окружении:

```bash
WEBKIT_DISABLE_SANDBOX_THIS_IS_DANGEROUS=1 cargo run
```

## Конфиг

Отдельного файла настроек нет. Список пинов, открытые файлы, панели и масштаб хранятся в сессии.
